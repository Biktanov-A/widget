# WidgetMaker (Android)

Прототип Android-приложения для создания виджетов-картинок на главном экране.

## Что уже реализовано
- Экран-заготовка приложения (`MainActivity`) с описанием сценария.
- `AppWidgetProvider` (`ImageWidgetProvider`) для показа выбранной пользователем картинки.
- Экран конфигурации виджета (`WidgetConfigureActivity`):
  - выбор изображения из галереи через системный picker;
  - сохранение `Uri` отдельно для каждого экземпляра виджета;
  - немедленное обновление виджета после сохранения.
- Простое локальное хранилище через `SharedPreferences` (`WidgetRepository`).

## Дальше можно добавить
1. Планировщик смены картинки по времени (`WorkManager`).
2. Несколько профилей/плейлистов картинок для каждого виджета.
3. Настройки масштабирования и скругления.
4. Поддержку разных размеров виджета.

## Стек
- Kotlin
- Jetpack Compose (экран приложения)
- Android App Widgets (`RemoteViews`)

## Быстрый сценарий использования
1. Установить приложение.
2. Добавить виджет **WidgetMaker** на главный экран.
3. Откроется экран настройки, выбрать картинку.
4. Виджет сразу покажет выбранное изображение.
